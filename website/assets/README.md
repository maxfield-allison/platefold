# Product-page images

`platefold-workspace.jpg` and `platefold-workspace-dark.jpg` show the actual desktop frontend with synthetic example paths. The interface uses the existing desktop test adapter and a preview rendered from the published sample PDF. These images illustrate the interface; they do not establish native installer qualification.

The page images are rendered from `docs/assets/samples/ladder-tour.pdf`:

| Image | PDF page | Page size |
| --- | --- | --- |
| `pdf-letter.jpg` | 1 | Letter portrait |
| `pdf-landscape.jpg` | 2 | Letter landscape |
| `pdf-a3.jpg` | 4 | A3 landscape |
| `pdf-custom.jpg` | 6 | Custom wide page |

Each page contains a different figure from the same sample document. The website switches between those existing pages; it does not convert uploaded documents.
