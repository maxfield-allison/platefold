# In development

These are possible follow-up areas after 1.0.0. They are not commitments or scheduled work.

!!! note "Plans can change"

    Nothing here is committed or scheduled.

## Accessible PDF output

Tagged output and source semantics are implemented. Native screen-reader acceptance remains open. Theme contrast and structural checks do not establish PDF/UA or WCAG conformance.

## More native packages

The first release covers Windows x64 installers, an Apple Silicon DMG, and a Linux x86-64 AppImage and `.deb`. Intel macOS, Windows on Arm, Linux on Arm desktop packages, `.rpm` and MSI packages can follow demonstrated demand and platform testing. The Linux container already supports amd64 and arm64.

## Broader desktop acceptance

Recorded Windows tests cover installation, file selection, preview, export, cancellation, upgrade and uninstall. The macOS app has Gatekeeper and signed-runtime automation, while Linux has CI package tests and a standard-user Ubuntu preview. Broader assistive-technology, desktop-environment and hardware coverage remains follow-up work.
